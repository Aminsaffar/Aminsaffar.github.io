1. Why use grid?

Tkinter has three geometry managers: pack, grid, and place.

  • pack — quick & simple, stacks widgets
  • grid — table-like layout (best for forms, dashboards, calculators)
  • place — absolute x/y positioning (rarely needed)

grid is the most powerful for structured layouts. Think of the window as a spreadsheet of rows and columns.

Rule of thumb: use grid for almost everything that looks like a form or table.

2. Basic Usage

import tkinter as tk

root = tk.Tk()
root.title("Grid Basics")
root.geometry("400x200")

# widget.grid(row=..., column=...)
tk.Label(root, text="Name:").grid(row=0, column=0)
tk.Entry(root).grid(row=0, column=1)

tk.Label(root, text="Email:").grid(row=1, column=0)
tk.Entry(root).grid(row=1, column=1)

tk.Button(root, text="Submit").grid(row=2, column=0, columnspan=2)

root.mainloop()

Rows and columns are 0-based. Empty rows/columns collapse automatically (they take no space).

4. The sticky Option (Most Important)

By default a widget sits in the center of its cell and keeps its natural size. sticky tells it which sides of the cell to stick to.

ValueMeaning
"n"North (top)
"s"South (bottom)
"e"East (right)
"w"West (left)
"nw", "ne", "sw", "se"Corners
"ew"Stretch horizontally
"ns"Stretch vertically
"nsew"Fill the entire cell
 
# Labels aligned to the right (east)
tk.Label(root, text="Username:").grid(row=0, column=0, sticky="e", padx=5, pady=5)
tk.Label(root, text="Password:").grid(row=1, column=0, sticky="e", padx=5, pady=5)

# Entries stretch to fill available width
tk.Entry(root).grid(row=0, column=1, sticky="ew", padx=5, pady=5)
tk.Entry(root).grid(row=1, column=1, sticky="ew", padx=5, pady=5)

# Make column 1 expand when window is resized
root.columnconfigure(1, weight=1)
Almost every good form uses sticky="e" on labels and sticky="ew" on entries.

5. rowspan & columnspan

Let a widget occupy multiple cells.

# Button spans two columns
tk.Button(root, text="Submit").grid(row=2, column=0, columnspan=2, sticky="ew", pady=10)

# Text widget spans 3 rows on the right side
text = tk.Text(root, width=30, height=8)
text.grid(row=0, column=2, rowspan=3, sticky="nsew", padx=10)

6. Making the Layout Resize (weight)

By default, extra space when the window grows goes nowhere. You must tell rows and columns how to share the extra space with weight. 

# Column 1 should grow, column 0 stays fixed
root.columnconfigure(0, weight=0)   # fixed
root.columnconfigure(1, weight=1)   # takes all extra width

# Row 2 (maybe a text area) should grow vertically
root.rowconfigure(2, weight=1)

# You can also set weight on a Frame if you nest grids
frame.columnconfigure(0, weight=1)
weight=0 (default) → no extra space
weight=1 → takes proportional extra space
Higher numbers get more space (e.g. weight=2 gets twice as much as weight=1).

Complete resizable example

import tkinter as tk

root = tk.Tk()
root.title("Resizable Grid")
root.geometry("450x300")

# Make the Entry column expand
root.columnconfigure(1, weight=1)
# Make the Text row expand
root.rowconfigure(2, weight=1)

tk.Label(root, text="Name:").grid(row=0, column=0, sticky="e", padx=8, pady=6)
tk.Entry(root).grid(row=0, column=1, sticky="ew", padx=8, pady=6)

tk.Label(root, text="Email:").grid(row=1, column=0, sticky="e", padx=8, pady=6)
tk.Entry(root).grid(row=1, column=1, sticky="ew", padx=8, pady=6)

tk.Label(root, text="Notes:").grid(row=2, column=0, sticky="ne", padx=8, pady=6)
text = tk.Text(root, height=6)
text.grid(row=2, column=1, sticky="nsew", padx=8, pady=6)

tk.Button(root, text="Save").grid(row=3, column=1, sticky="e", padx=8, pady=10)

root.mainloop()

7. Padding

# Same padding on both sides
widget.grid(..., padx=10, pady=5)

# Different left/right or top/bottom
widget.grid(..., padx=(20, 5), pady=(10, 0))   # (left, right) / (top, bottom)

# Internal padding (grows the widget itself)
widget.grid(..., ipadx=10, ipady=8)

8. Uniform Column / Row Groups

Sometimes you want several columns to have the same width even if their content differs. 

# All columns in the "btn" group will be the same width
root.columnconfigure(0, weight=1, uniform="btn")
root.columnconfigure(1, weight=1, uniform="btn")
root.columnconfigure(2, weight=1, uniform="btn")

tk.Button(root, text="One").grid(row=0, column=0, sticky="ew", padx=4)
tk.Button(root, text="Two").grid(row=0, column=1, sticky="ew", padx=4)
tk.Button(root, text="Three").grid(row=0, column=2, sticky="ew", padx=4)

9. Practical Form Examples

Classic two-column form

import tkinter as tk
from tkinter import ttk

root = tk.Tk()
root.title("User Form")
root.geometry("420x320")
root.columnconfigure(1, weight=1)

fields = [
    ("Full Name", 0),
    ("Email", 1),
    ("Phone", 2),
    ("City", 3),
]

entries = {}
for label_text, row in fields:
    ttk.Label(root, text=label_text + ":").grid(
        row=row, column=0, sticky="e", padx=(15, 8), pady=8
    )
    entry = ttk.Entry(root)
    entry.grid(row=row, column=1, sticky="ew", padx=(0, 15), pady=8)
    entries[label_text] = entry

# Notes (taller)
ttk.Label(root, text="Notes:").grid(row=4, column=0, sticky="ne", padx=(15, 8), pady=8)
notes = tk.Text(root, height=4)
notes.grid(row=4, column=1, sticky="ew", padx=(0, 15), pady=8)
root.rowconfigure(4, weight=1)

# Buttons row
btn_frame = ttk.Frame(root)
btn_frame.grid(row=5, column=0, columnspan=2, pady=15)

ttk.Button(btn_frame, text="Cancel").pack(side="left", padx=6)
ttk.Button(btn_frame, text="Save").pack(side="left", padx=6)

root.mainloop()

Calculator-style button grid

import tkinter as tk

root = tk.Tk()
root.title("Keypad")

buttons = [
    ["7", "8", "9", "/"],
    ["4", "5", "6", "*"],
    ["1", "2", "3", "-"],
    ["0", ".", "=", "+"],
]

for r, row in enumerate(buttons):
    root.rowconfigure(r, weight=1)
    for c, text in enumerate(row):
        root.columnconfigure(c, weight=1, uniform="btn")
        tk.Button(root, text=text, font=("Arial", 16)).grid(
            row=r, column=c, sticky="nsew", padx=2, pady=2
        )

root.mainloop()

10. Best Practices & Gotchas

  • Never mix pack and grid in the same parent. You can mix them in different frames.
  • Always set weight on columns/rows that should grow.
  • Use sticky="ew" (or "nsew") together with weight, otherwise the widget stays its natural size.
  • Prefer ttk widgets for a more native look (they still work with grid).
  • For complex UIs, put groups of widgets inside Frames and grid the frames.
  • You can call grid_remove() to hide a widget temporarily and grid() again to restore it (keeps settings).
  • grid_forget() removes the widget from the layout completely.
# Hide / show example
widget.grid_remove()   # hide but remember options
widget.grid()          # show again with same options

widget.grid_forget()   # remove completely
