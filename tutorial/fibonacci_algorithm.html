01 · The idea

One sequence, many algorithms

Each Fibonacci number is built from the two values before it. The recurrence is simple; the implementation determines how much work the computer repeats.

F(0) = 0 · F(1) = 1
F(n) = F(n − 1) + F(n − 2)

03 · The algorithm family

Compare five ways to compute F(n)

Select an approach to read its idea, complexity, and a short visual demonstration.

Rolling window

Start with 0 and 1. Replace the pair with (current, previous + current) until the target index is reached.

TimeO(n)
Extra spaceO(1)
Best forSimple, large inputs

Why it is efficient

The algorithm never stores the entire history. It preserves exactly the two values needed by the recurrence, making memory usage constant.

Invariant: at the start of iteration i, previous = F(i − 2) and current = F(i − 1).

Direct translation

For n > 1, call the function twice: once for n − 1 and once for n − 2. This mirrors the mathematical definition.

TimeO(2ⁿ)
Call stackO(n)
Main issueRepeated subproblems

The hidden cost

Computing F(5) asks for F(4) and F(3). But F(4) asks for F(3) again, so the same work branches repeatedly.

Remember answers

Memoization adds a cache. Before making a recursive call, check whether the answer already exists; if it does, return it immediately.

TimeO(n)
Extra spaceO(n)
StyleTop-down recursion

Trade-off

Memoization preserves the recursive shape while eliminating duplicate work. The cache costs memory, but it converts exponential time into linear time.

Build from the bottom

Start with the known base cases, then fill an array from left to right until the target index is reached.

TimeO(n)
Extra spaceO(n)
StyleBottom-up dynamic programming

When it helps

The full table gives instant access to every earlier value. That is useful when later logic needs more than just the final Fibonacci number.

Split the problem

Fast doubling computes a pair (F(n), F(n+1)) using identities that halve n at each recursive level.

TimeO(log n)
Extra spaceO(log n)
Key ideaHalve the index

Useful identities

F(2k) = F(k)[2F(k+1) − F(k)]
F(2k+1) = F(k)² + F(k+1)²

Because the index is halved repeatedly, this is the fastest option in the family for very large n.

05 · Takeaways

What should you remember?

State

Two rolling variables are enough for the iterative solution.

Repetition

Naive recursion solves the same smaller problems many times.

Reuse

Memoization and tabulation store results to avoid duplicate work.

Scale

Fast doubling reduces the number of levels from n to log n.

Precision

JavaScript numbers lose exact integer precision beyond 2⁵³ − 1; use BigInt for huge indices.
