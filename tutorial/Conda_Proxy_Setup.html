Conda Proxy Setup

Learn how to install packages behind restricted networks using proxy configuration.

Temporary Proxy Setup

Use environment variables for quick setup.


export HTTP_PROXY=http://user:pass@ip:port
export HTTPS_PROXY=http://user:pass@ip:port

conda install numpy
Use this method for one-time installs.

Permanent Setup


conda config --set proxy_servers.http http://user:pass@ip:port
conda config --set proxy_servers.https http://user:pass@ip:port
Saved inside .condarc.

Troubleshooting

SSL Error

conda config --set ssl_verify false
Timeout Issue

conda config --set remote_connect_timeout_secs 30
Disable SSL only if necessary.
