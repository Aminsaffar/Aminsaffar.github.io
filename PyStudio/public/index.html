QUICK GUIDE

A real Python runtime, right here.

PyStudio runs Python with Pyodide and WebAssembly in a dedicated browser worker. Your code and projects stay in this browser; running Python does not call an execution backend.

Only run code you trust.Browser execution is isolated from the page UI, but it is not a complete security sandbox. Code can use CPU and memory and may access network-capable Python APIs.

Interactive input and hosting

Python input() uses a shared-memory bridge between the Worker and terminal. Browsers require a secure, cross-origin-isolated page for this feature. Cloudflare Pages uses the included _headers file. GitHub Pages uses the local COI service worker and may reload once after its first install. Also see README.md for deployment and local development steps.

Install on a phone

Choose Install in the top bar when available. On iPhone or iPad, open this page in Safari, tap Share, then choose Add to Home Screen. The offline page is available after installation, but the editor and Python runtime load from public CDNs and may need an internet connection.

Jupyter notebooks

Use the + button to create a .ipynb notebook, or use Import to open one. Add Python or Markdown cells, run one cell or Run all, and download the notebook as standard nbformat 4 JSON. Code cells share the in-browser Pyodide session. Text output and errors are supported; rich widgets and arbitrary HTML output are not. Python input() still uses the integrated terminal.

PYSTUDIO ON YOUR PHONE

Take PyStudio with you.

Add PyStudio to your device's Home Screen to open it in its own app window.

  1. In Safari, tap Share, then choose Add to Home Screen and confirm with Add.
  2. Open your browser menu and choose Install app or Add to Home Screen.

Your projects stay in this browser. The editor, Python runtime, and compatible packages come from public CDNs and may require an internet connection.
